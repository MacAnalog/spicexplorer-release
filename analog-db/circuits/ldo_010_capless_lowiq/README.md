# ldo_010_capless_lowiq — capless low-Iq LDO (IHP SG13G2, 1.5 V lv devices)

A **capless** low-quiescent-current low-dropout regulator: a double-mirror
flipped-voltage-follower (FVF) output stage under a slow, high-gain two-stage error amplifier,
biased from a poly resistor rather than an ideal current source. No off-chip output capacitor —
the only C on `vout` is the on-chip MIM array `XCOUT` (4 x 5 pF) plus a 1 pF pad/wiring
allowance the benches add.

Ported from an agent-first design repo @ `40cad45`
(branch `feat/001-reference`), where it is the local circuit `ldo_ihp_capless` and carries
its own certification lane (frozen decks + a signed ledger + an independent sign-off).
This entry is the catalogued, drift-guarded, layout-bearing form of the SAME design point.

## Topology

    vdd ──┬──────────────────────────────────────────────┬── XMP (pass) ──┬── vout
          │                                              │                │
          │  resistor-referenced bias      error amp     │  double-mirror │  XCOUT (MIM)
          │  XRB → XMB0 → XMB1 → XMBP      XMT/XM1..XM4   │  FVF fold      │
          │                                XM5/XM6/XCC    │  XMC XMA XMB   │  XR1/XR2 divider
          │                                               │  XMCP XMD XMS  │  (+ XCFF lead)
    vss ──┴───────────────────────────────────────────────┴────────────────┘

- **Output stage** — pass PMOS `XMP`; control PMOS `XMC` whose *source is the output*. `XMC`'s
  current is folded through an NMOS 1:1 mirror (`XMA`/`XMB`) and a PMOS 1:1 mirror
  (`XMCP`/`XMD`) onto the pass gate as a **pull-up**, with a constant sink `XMS` pulling the
  gate down. The fold — not a plain FVF — is what lets the gate reach `vdd - Vsd,sat`, so the
  pass device turns fully OFF at hot/fast corners, which a plain FVF (gate ≤ vout) cannot do.
- **Outer loop** — a PMOS-input 5T OTA (`XM1..XM4`, tail `XMT`) into a Miller-compensated
  common-source stage (`XM5`/`XM6`, `XCC`) compares the 1:1-divided output with the ideal
  reference and sets the FVF control voltage. It sets DC accuracy, PSRR and load/line
  regulation; the FVF's local loop is the fast transient path.
- **Bias** — `XRB` (poly) into the NMOS diode `XMB0`, mirrored to the gate sink and, via the
  PMOS diode `XMBP`, to the error-amp tail. No ideal current sources anywhere.
- **`XCFF`** — a feed-forward MIM across the top divider resistor: a lead zero that cancels the
  divider-node pole the resistors' own substrate capacitance makes.

## The drawn device set (not the schematic shorthand)

`abstract/netlist.spice` carries the devices the **layout of record actually draws**, because
the difference is electrical and the benches simulate this file:

- `XMP` is `m*nf_mult` unit fingers of `w/nf_mult` — deliberately *not* `ng`, which would pass
  `nf` to the PSP model and bank a ~10 mV load-step credit that is a model parameter, not a
  layout.
- every common-centroid member (`XM1..XM4`, `XMS`, `XMB1`, `XMB0`) is two half-width cards;
- `XR1`/`XR2` are 8 series segments each and `XRB` is 5, as the serpentines are drawn.

LVS is unaffected: the deck compares W and L with `--combine_devices`.

## Analyses and the scoreboard row

Thirteen bindings of ten `ldo`-class templates — `psrr`/`psrr_1m` are the same bench at 1 kHz
and 1 MHz, `ac_loopgain{,_lo,_hi}` the same loop measurement at 1 / 0.1 / 10 mA.

`scoreboard/ihp-sg13g2/4520e22ad0.json` reproduces the design repo's verifier-signed candidate
scorecard **to the last recorded digit on every metric** (native ngspice-45, corner `tt`, 27 C):
`v_out` 1.199499 V, `i_q` 33.805 µA, `v_dropout` 104.671 mV, PSRR(1 kHz) 70.007 dB,
undershoot 115.057 mV, PM 72.506°, `vn_out_rms` 372.93 µV rms. All eight spec-bounded metrics
pass; the remaining canonical metrics are recorded without a limit (the design was never
specified against them — the convention `ldo_009` states).

The lowered netlist here is GENERATED by `analog-db generate`; the design repo lowered the same
abstract netlist by hand. The two agree device-for-device and value-for-value — only the card
order and the `w=`/`l=` key order differ, which SPICE does not see.
