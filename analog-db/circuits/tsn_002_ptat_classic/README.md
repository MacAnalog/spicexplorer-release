# tsn_002_ptat_classic — classic self-biased PTAT reference core

**Promoted** from the `sfe_ptat_classic` reference entry (AnalogGym "Sensing Front End",
BSD-3-Clause). Class `temp_sensor`. Ports `vdd vout vss`.

A self-biased PTAT current reference: a PMOS current mirror (XM3/XM4) copies a current set by the
Vgs mismatch of a W-ratioed NMOS pair (XM0 degenerated by R0, XM1 diode-connected) developed across
R0. **Output choice:** `vout` is exposed at the R0 top node (the ground-referenced PTAT voltage
I·R0), not the upstream supply-referenced `vsense` mirror node — so it behaves as a proper
reference (positive slope, real supply rejection). A 4:1 pair W-ratio biases the loop off the
trivial I=0 point that the upstream 1:1 TSMC sizing sits at off-technology.

- **Open-PDK bindings:** `ihp-sg13g2` (1.5 V), `sky130` (1.5 V shared supply).
- `gf180mcu` binding added via `analog-db add-binding --from ihp-sg13g2` (untuned transfer; T3/T4 sim-smoke passes).
- **Analyses:** `dc_op`, `temp_sweep`, `line_sweep`, `psrr`.
- **Reference binding:** original TSMC-180nm AnalogGym decks under `spectre/180nm/`.
- **Structure:** `find_subcircuits` detects the PMOS current mirror (`cm.pmos.simple`, ref XM3 → out XM4).
