# corpora/ferrosim — upstream pointer (no decks redistributed)

The ferrosim reference corpus is **not redistributed here**. Upstream:
<https://github.com/Arcadia-1/ferrosim> (Token Zhang, MIT License).

The `ferrosim_*` entries in this database are **index/pointer entries only**
(`kind: reference`): each `circuit.yaml` records the upstream repository,
designer, and license, and the harness runs a pointer-level Tier-0 (schema +
provenance) on them. No upstream netlists, testbenches, or simulator decks are
vendored in this repository, and no foundry-PDK content of any kind ships here.
