## Abstraction decision (recorded)

The **abstract** netlist (`circuits/<id>/abstract/netlist.spice`) is the **clean topology
core** with PDK-neutral `nmos`/`pmos` tokens. PDK-implementation cruft — the enable/power-down
network (`XM7…XM13` / `XMpd*`), decoupling devices, bias-buffer Vsources, `Vmeas` ammeters —
is **not** part of the abstract topology. It is preserved only in the per-PDK
`netlist.legacy.spice` (the real, runnable, optimizer-facing artifact). The clean
`pdk/<pdk>/netlist.spice` is GENERATED by lowering the abstract core. For `amp_001_5t` (Phase 0):
abstract = 6 devices (input pair + PMOS mirror load + tail + mirror ref); the IHP enable
network lives in `pdk/ihp-sg13g2/schematic/` provenance only.
